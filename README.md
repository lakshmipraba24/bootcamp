Developed and deployed an end-to-end AI-powered assistive communication system for individuals with Parkinson's-induced dysarthria. Designed a custom Convolutional Recurrent Neural Network (CRNN) to decode slurred and unintelligible speech into text, followed by text-to-speech synthesis to generate clear, natural-sounding speech. Implemented audio preprocessing and feature extraction using MFCC and Mel-spectrograms, and optimized the complete pipeline for real-time edge deployment on Raspberry Pi .The model was evaluated using standard performance metrics to assess its reliability and effectiveness.This project strengthened my understanding of digital signal processing,speech feature extraction,deep learning,model evaluation,and AI-based healthcare applications.
